# Deployment Guide

## GitHub

Upload all files in this project to the repository.

Important:
- Keep `app.py` and `Helix_Energy_Intelligence_Simulation_Data.xlsx` in the same folder.
- Keep `requirements.txt` in the repository root.

## Streamlit Community Cloud

Use:
- Branch: main
- Main file: app.py

The app loads the Excel workbook relative to `app.py`.
