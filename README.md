# HELIX Energy Intelligence – Simulation

Client/CEO-friendly energy dashboard simulation.

## Sidebar / Navigation

- Overview
- Comparison & Drilldown
- Meter Intelligence
- Anomalies & Actions
- Data Quality

## Main workflow

**Monitor → Compare → Identify → Understand → Act → Verify**

Main drill-down:

**Total Energy → Building → Meter**

## Run locally

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Open:

`http://localhost:8501`

> All readings, comparisons, anomalies and savings values are simulated.
